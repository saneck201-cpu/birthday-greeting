# birthday-greeting

Сайт-поздравление с 18-летием. Наверху заяц-восемнадцать (на него можно нажать, и он пошевелит ушками), ниже 18 шариков: каждый лопается и открывает пожелание. После последнего шарика появляется торт со свечой и конфетти.

## Как открыть

Это обычная статическая страница, сборка не нужна. Достаточно открыть `index.html` в браузере.

Чтобы выложить в интернет, включи GitHub Pages: Settings → Pages → Deploy from a branch → ветка `main`, папка `/ (root)`.

## Что поменять под себя

- **Пожелания и подпись** лежат в самом начале `script.js`: массив `WISHES` (ровно 18 штук) и константа `SENDER`.
- **Имя** по умолчанию «зайка». Подставить другое можно через адрес: `…/?name=Аня`.
- **Цвета** собраны в переменных в начале `style.css`.

## Файлы

- `index.html` — разметка и рисованные SVG (цифра 18 с ушками, торт).
- `style.css` — оформление и анимации.
- `script.js` — шарики, звук, конфетти, свеча.

Анимации отключаются, если в системе включено «уменьшить движение».
